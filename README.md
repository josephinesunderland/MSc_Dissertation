Code for my MSc Dissertation Project:
'Determining the Demographic Drivers of Population Change in the Steppe Eagle (Aquila nipalensis)'

The code is split into three main sections:
1. Data cleaning (Scripts)
2. Bayesian statistical models, known-fate to determine survival rate and GLMMs to determine reproduction
3. Matrix Population Models to determine population growth rate (lambda) and perform sensitivity analyses

The data was provided by the RSPB in collaboration and is not available to share but the code is fully accessible and reproducible for similar projects.
